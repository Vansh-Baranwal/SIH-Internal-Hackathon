# Manual Tasks: Member 6 (Lunar Hazard Mapper)

This document delineates the tasks that cannot be reliably automated and require manual human intervention or verification.

## 1. Scientific & Assumption Verification
You must manually review and verify the following physical assumptions before they are accepted as "facts" for the final SIH presentation:
- [ ] Lunar gravity assumption (`1.62 m/s²`)
- [ ] Lander mass
- [ ] Maximum thrust capabilities
- [ ] Engine Specific Impulse (Isp)
- [ ] Δv budget constraints
- [ ] Touchdown velocity limits (vertical and horizontal)
- [ ] Lander footprint dimensions
- [ ] Lander clearance thresholds
- [ ] Coordinate system conventions

*(Note: If official values are unavailable, document them explicitly as a "Research Assumption" in `configs/project.yaml` or similar).*

## 2. Blender Environment Setup
- [ ] **Blender Installation:** Install Blender 4.x (exact minor version documented in `docs/SETUP.md`) locally on the demonstration machine.
- [ ] **Scene Initialization:** Open and test the `.blend` scene generated by the Python initialization script to ensure it correctly maps into the installed version.

## 3. Visual & Asset Checks
- [ ] **Terrain Mesh Quality:** Visually inspect the generated M3 DEM terrain mesh in Blender to confirm LOD/decimation is acceptable and physical scale is maintained.
- [ ] **Lander Scale:** Compare the visual scale of the imported lander 3D asset against the terrain to ensure realistic proportions.
- [ ] **Camera & Lighting:** Adjust the final camera angles, lighting, and rendering settings for the presentation.

## 4. Interaction Validation
- [ ] **Ray-casting (Click-to-Land):** Test the Blender mouse interaction interactively to ensure clicked world coordinates accurately transform into the correct local simulation frame without offsets.

## 5. Demo Rehearsal
- [ ] **Hero Scenario Run-through:** Manually execute the complete sequence: select lander -> click safe site -> inject hazard -> invalidate -> re-plan -> divert -> touchdown. Ensure the UI updates properly and the trajectory divergence is visually clear and easily explainable to the SIH judges.
