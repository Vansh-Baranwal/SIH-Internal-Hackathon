# Setup Instructions

1. Clone repo
2. Create virtual environment
3. Install package in editable mode (`pip install -e .`)
4. Optionally install pinned dependencies (`pip install -r requirements.txt`)
5. Run tests (`pytest tests/`)
6. Generate synthetic data (`python scripts/generate_synthetic_data.py`)
7. Run pipeline (`python scripts/run_pipeline.py`)
8. Open Blender
9. Run Blender scripts
